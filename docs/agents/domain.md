# Domain docs

This project uses a single context: root GLOSSARY.md and relevant decisions under docs/adr/ when those exist.

Before exploring or changing product code, read GLOSSARY.md and any ADRs covering the work. If an optional document is absent, continue without creating it merely for completeness. Use Edition, Story, Source article, Briefing, Beyond Your Bubble, Preferred region and Reading length as defined; keep Skip distinct from Less like this.

PRODUCT.md records confirmed product behavior. The release specification distinguishes those decisions from proposed engineering defaults. Surface conflicts with existing ADRs instead of silently overriding them.
